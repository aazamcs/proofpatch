# Submission requirements we checked

Checked on 26 September 2026 against:
- Event: https://lablab.ai/ai-hackathons/ibm-bob-2-hackathon
- Official submission guide: https://lablab.ai/delivering-your-hackathon-solution

The event page describes a 48-hour IBM Bob 2.0 development hackathon. The detailed submission guide requests:

| Requirement | Our deliverable / owner |
|---|---|
| Clear title; short description ≤255 characters; long description ≥100 words; tags | SUBMISSION_COPY.md |
| PNG/JPG cover; 16:9 recommended | COVER.png, 1280×720 |
| MP4 presentation, maximum 5 minutes: introduction, PDF discussion, functions | DEMO.mp4 and matching transcript |
| PDF slides | PITCH.pdf; editable PITCH.pptx also included |
| Public GitHub repository | Student B publishes this repository at our supplied GitHub URL |
| Exported IBM Bob reports of relevant tasks/sessions | Student A attaches genuine original reports under evidence/bob/ |
| Interactive application URL | Student B deploys app.py and tests access while signed out |

The guide's four judging dimensions are presentation, business value, application of technology and originality. Our slides and judges' guide address each. The guide recommends user-interaction footage; our supplied technical walkthrough shows actual recorded verification results. DEMO_SCRIPT.md also provides an optional screen-recording sequence.

Market scope, revenue, competitive positioning and future plans are recommendations. We define broad and initial audiences and a pilot/revenue hypothesis. We do not invent numeric TAM/SAM, customer traction or time-saving percentages.

Student B verifies the final form, individual registrations, team listing and final submission confirmation in the event account. This checklist assigns the remaining account-specific work to the students, rather than requiring the mentor to contact organizers about information already published.
